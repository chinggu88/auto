 핏빛서버 메모리 매크로 - 다음에 할 일

[만들어진 것]
  pit_auto.exe   사냥 매크로 본체 (GUI)
  memprobe.exe   먼저 이걸 돌려서 메모리 읽기가 되는지 확인한다
  memcalib.exe   몹 타겟 집기를 쓸 때만 필요하다
  mem.json       오프셋을 적어두는 파일. exe 옆에 두고 메모장으로 고친다

[중요] exe 는 처음 뜰 때 압축을 푸느라 4~5초쯤 까만 창만 보인다. 고장이 아니다.
       파이썬이 깔려 있으면 python memprobe.py 로 돌리는 쪽이 훨씬 빠르고,
       cmd 창에 출력이 그대로 남아서 편하다.

---------------------------------------------------------------------
제일 쉬운 길 : hpfind
---------------------------------------------------------------------

    python hpfind.py

HP 숫자를 몰라도 되고, 명령을 여러 번 칠 필요도 없다.
게임 창에 들어가 있는 채로 :

    몹한테 맞아서 HP 를 줄인다  ->  [1]
    또 맞는다                   ->  [1]
    또 맞는다                   ->  [1]

    (중단은 [2]. 다른 키를 쓰려면 python hpfind.py --key insert --quit end)

세 번이면 끝난다. mem.json 까지 알아서 저장하고,
HP 가 맞게 읽히는지 바로 보여준다. (고치기 전 mem.json.bak 으로 백업한다)

아래 순서는 수동으로 하고 싶을 때만 보면 된다.

---------------------------------------------------------------------
순서 (수동)
---------------------------------------------------------------------

1) 클라이언트 찾기
     python memprobe.py --list
   또는 memprobe.exe 를 더블클릭 (출력을 다 읽고 엔터를 눌러 닫는다)

   핏빛서버 클라이언트는 Lin.exe 다.
   게임을 2창 띄우면 Lin.exe 가 2줄 나온다. 창 제목으로 구분한다.
   PID 는 게임을 다시 켤 때마다 바뀐다. 정상이다. mem.json 에 적지 않는다.

2) 읽기가 되는지 판정
     python memprobe.py --pid <PID>
   또는 쓸 게임 창을 클릭해 맨 앞에 두고
     python memprobe.py --fg

   OpenProcess 가 실패하면 여기서 끝이다. 관리자 권한으로 다시 해보고,
   그래도 안 되면 메모리 방식은 못 쓴다 (main.py 의 이미지 방식을 계속 쓴다).

3) 오프셋 찾아서 mem.json 에 넣기
   memprobe 가 찍어준 모듈 베이스 주소를 기준으로 상대값을 적는다.
     상대값 = CheatEngine 에서 찾은 절대주소 - 모듈 베이스
   먼저 chains 의 hp / hp_max 만 채워도 된다.

4) 값이 진짜 따라 움직이는지 확인
     python memprobe.py --watch hp,hp_max --fg
   게임에서 맞거나 회복하면서 숫자가 따라 변하는지 눈으로 본다.
   게임을 껐다 켜도 같은 값이 잡혀야 쓸 수 있는 오프셋이다.

5) 객체 목록 (혈맹 판별 / 몹 타겟용. 안 해도 HP 귀환은 된다)
     python memprobe.py --objs --fg
   몹과 플레이어의 type 값, 그리고 혈맹명 문자열을 여기서 확인해
   mem.json 의 objlist 와 mob_types / player_types 를 채운다.

6) 몹 타겟을 쓰려면 화면 좌표 변환 맞추기
     python memcalib.py --fg
   몹에 커서를 올리고 insert 를 5번 이상, 끝나면 end.

7) pit_auto.exe 에서 [메모리에서 상태 읽기] 켜기
   내 혈맹명을 꼭 적는다. 안 적으면 보이는 모든 혈맹이 적으로 잡혀 바로 귀환한다.

---------------------------------------------------------------------
메모리 감지를 끄면 기존 main.py 와 완전히 똑같이 동작한다.
config.json / pit.json 은 exe 를 처음 실행하고 [설정 저장] 을 누르면 생긴다.
게임이 관리자 권한으로 돌면 exe 도 관리자 권한으로 실행해야 한다.

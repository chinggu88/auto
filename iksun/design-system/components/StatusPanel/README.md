# StatusPanel

창 맨 위의 상태 판 — 실행 상태, HP/MP readout, 메모리 읽기 상태를 한 줄 카드에 모아 다른 영역을 보지 않아도 현재 상황을 판독하게 한다.

- 배경 `surface`, 테두리 `line` 1px, 모서리 `radius-lg`, 안쪽 여백 `space-3`/`space-4`.
- 왼쪽: 실행 상태 문구(`title`) + StatusBadge. `대기`, `사냥 중`, `버프 중 (공격 일시정지)`, `도주 (F8)` 처럼 `isattack` 를 멈춘 이유를 그대로 적는다.
- 가운데: HP·MP 를 `readout`(고정폭)로. 임계값 이하인 쪽만 `state-danger`. 아래에 `caption` 으로 `메모리 · 0.4초 전` 같은 출처와 나이.
- 오른쪽: 메모리 읽기 상태 — `정상`, stale 이면 `판단불가` 배지와 이유 한 줄. 판단불가인 동안 사냥·쫄 동작은 멈춘다.
- 사용처가 제공할 것: 상태 문구, HP/MP 퍼센트와 임계값, 메모리 읽기 상태, 갱신 시각.

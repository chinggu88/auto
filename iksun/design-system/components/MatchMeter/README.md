# MatchMeter

템플릿 매칭(또는 메모리 읽기) 한 항목의 현재 신뢰도를 임계값과 나란히 보여주는 가로 막대 — "왜 반응했는지/왜 안 했는지"를 숫자로 증명한다.

구성(왼쪽→오른쪽): 항목 이름(`body`) · 막대 · 수치 `0.82 / 0.70`(`value`, 고정폭) · StatusBadge.

- 막대 채움: 신뢰도 ≥ 임계값이면 `state-ok`, 미만이면 `state-idle`, 읽지 못했으면(값 없음) 채움 없이 `판단불가`.
- 임계값 위치에 2px `ink` 세로 눈금을 항상 그린다. 이미지마다 0.2~0.8로 다르기 때문에 눈금이 없으면 막대 길이를 해석할 수 없다.
- 막대 바탕 `surface-raised`, 테두리 `line-strong` 1px, 높이 8px, 모서리 `radius-sm`.
- 값은 소수 둘째 자리까지. 갱신 시각이 1초 넘게 지나면 수치를 `ink-muted` 로 바꿔 오래된 값임을 표시한다.
- 사용처가 제공할 것: 이름, 신뢰도(또는 `None`), 임계값, 출처, 마지막 갱신 시각.

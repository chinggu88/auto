# Lin Auto 제어판

화면 인식 매크로(`main.py` / `pit.py` 의 `App`)를 위한 Windows 데스크톱 UI 규칙. 목표는 하나 — **사용자가 매크로가 지금 무엇을 보고, 얼마나 확신하며, 왜 그렇게 행동하는지 한눈에 판독할 수 있게 하는 것.** 화려함은 목표가 아니다. 장식은 판독을 방해하는 소음으로 취급한다.

## 원칙

1. **판정은 근거와 함께 보인다.** 모든 인식 결과는 `값 · 출처 · 신뢰도/임계값 · 갱신 시각` 네 가지를 같이 표시한다. "HP 정상"이 아니라 `HP 72% · 메모리 · 0.4초 전`.
2. **세 가지 상태를 섞지 않는다.** 코드의 tri-state(`True` / `False` / `None`)를 그대로 화면에 옮긴다.
   - `True` 확인됨 → `state-ok`
   - `False` 아님 → `state-idle` (중립 회색. 위험이 아니다)
   - `None` 판단 불가 → `state-unknown` (이미지로 폴백, stale)
   - 위험 행동(도주·귀환·적대 혈맹) 은 별도의 `state-danger`
3. **색만으로 구분하지 않는다.** 모든 상태 색은 텍스트 라벨(`확인`, `아님`, `판단불가`, `위험`)을 동반한다. 색끼리는 밝기로도 구분되며, 성공/주의는 파랑/주황 축이라 적록색약에도 갈린다.
4. **숫자는 고정폭.** 갱신될 때마다 자리가 흔들리면 읽을 수 없다. 수치·키·좌표·로그는 `mono` 가족.
5. **움직임 없음.** 깜빡임, 애니메이션, 그라데이션을 쓰지 않는다. 상태가 바뀌면 값과 색이 바뀔 뿐이다. 바뀐 사실은 로그가 기록한다.
6. **정지는 언제나 보인다.** 동작 중에도 정지 방법(`tab = 정지`)이 주 버튼 자리에 그대로 표시된다.

## 화면 구성 (위에서 아래로)

| 영역 | 내용 | 기존 코드 |
|---|---|---|
| 상태 판 | 실행 상태, HP/MP readout, 인식 출처(메모리/이미지) | 신규 |
| 인식 표 | 감지 항목별 MatchMeter (신뢰도 vs 임계값) | `locateCenterOnScreen(confidence=…)` |
| 버프 키 설정 | F5–F12 KeyRow 표 | `버프 키 설정 (f5 ~ f12)` |
| 동작 | 공격 사용, 칼 탐지 거리, 새로고침 트리거, 소리 감지 | `동작` LabelFrame |
| 설정 바 | 저장 / 불러오기 / 기본값 | `cfgbar` |
| 주 버튼 | 시작하기 ↔ 동작 중 (tab = 정지) | `self.btn` |
| 로그 | LogLine, 최신이 아래 | `로그` Text |

## 색

어두운 테마가 기본이다(게임 화면 옆에 띄워도 눈부시지 않다). 밝은 테마는 같은 토큰 이름으로 값만 바뀐다.

- 면: `bg` → `surface`(패널) → `surface-raised`(입력·로그·표 헤더)
- 글자: `ink` 본문, `ink-muted` 보조 설명 — 둘 다 `surface` 위 4.5:1 이상
- 선: 구분선은 `line`, 컨트롤 테두리는 반드시 `line-strong` (3:1)
- 주 행동은 `accent` 하나뿐. 상태 색을 버튼에 쓰지 않는다.

## 글자

Windows 기본 `Malgun Gothic` + 고정폭 `Consolas`. 웹 폰트는 쓰지 않는다(exe 에 번들할 필요 없음). tkinter 는 포인트 단위라 각 스타일 usage 에 tk 튜플을 적어 두었다. `caption`(9pt)보다 작은 글자는 금지.

## 간격과 모서리

4px 격자: `space-1` 4 · `space-2` 8 · `space-3` 12 · `space-4` 16 · `space-6` 24. 모서리는 `radius-sm` 2 / `radius-md` 4 / `radius-lg` 6 까지만 — 둥근 알약 모양 금지.

## 아이콘

쓰지 않는다. 상태는 텍스트 라벨 + 색 사각형(8×8, `radius-sm`)으로 표시한다. 아이콘 해석에 드는 시간보다 `확인` 두 글자가 빠르다.

## 문구

- 존댓말 없이 짧게: `시작하기`, `설정 저장`, `판단불가 — 이미지로 대체`
- 원인을 숨기지 않는다: `메모리 stale (연속 5회 실패) — 이 세션은 이미지 인식` 처럼 이유와 결과를 함께.
- 로그는 `시:분:초  레벨  출처  내용` 순서 고정.

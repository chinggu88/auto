# 키 매퍼 (F4~F12)

키보드에 없는 키(F1, 숫자패드 등) 대신 쓸 키를 직접 지정하는 리매퍼.

## 실행

```
pip install keyboard
python keymapper.py
```

exe로 묶으려면 (Windows):

```
build_keymapper.bat
```

## 사용법

1. 각 행의 **누를 키 [설정]** 을 누르고 실제 누를 키를 누른다 (조합키도 됨: `ctrl+q` 등)
2. **나갈 키** 는 기본으로 F4~F12가 들어가 있음. [설정] 으로 변경 가능
3. **[시작]** 을 누르면 매핑 동작. **[정지]** 로 해제
4. **[저장]** 하면 `keymap.json`에 보관, 다음 실행 때 자동 불러오기

## 주의

- 한 글자 키(`q` 같은)를 트리거로 쓰면 그 키 입력이 가로채지니 조합키 권장
- 게임에서 동작하지 않으면 **관리자 권한**으로 실행
